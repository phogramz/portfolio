# Портфолио и карта развития

Статический сайт без сборки и без сервера: обычные HTML, CSS и JavaScript.
Работает на GitHub Pages прямо из ветки `main`.

## Как посмотреть локально

```
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Открыть `index.html` двойным щелчком
не получится: браузер не загружает модули с диска.

## Где что лежит

| Файл | Что в нём |
| --- | --- |
| `data/career.js` | Основной трек: траектория к solution-архитектуре |
| `data/map.js` | Лаборатория (hobby-трек): IoT, связь, робототехника |
| `data/posts.js` | Список статей блога: заголовок, трек, теги, черновик или нет |
| `posts/` | Тексты статей в Markdown: `<slug>.ru.md`, по желанию `<slug>.en.md` |
| `data/projects.js` | Проекты, исследования, статьи и заметки |
| `data/profile.js` | Имя, описание, опыт, образование, контакты |
| `images/` | Фотографии и картинки к проектам |
| `assets/app.js` | Логика сайта: страницы, дерево, переключение языка |
| `assets/styles.css` | Оформление |

## Как добавить проект

1. Положите картинки в `images/`.
2. Добавьте запись в `data/projects.js` по образцу существующих.
3. В поле `nodes` укажите id узла из `data/map.js`. Проект появится
   на странице этого узла и на главной.

## Как изменить статус узла

В `data/map.js` поменяйте `status` на одно из значений:
`solid` (уверенно владею), `learning` (изучаю), `planned` (в планах).

## Языки

Все тексты хранятся парами `{ ru: '...', en: '...' }`. Если английского
варианта нет, сайт покажет русский.

## Блог

1. Создайте файл `posts/<slug>.ru.md` с текстом статьи.
2. Добавьте запись в `data/posts.js`: `slug`, `track` (`main` или `lab`), `tags`,
   `nodes`, заголовок и краткое описание.
3. Пока стоит `draft: true`, статья скрыта из списков. Все черновики открываются
   по адресу `#/blog/drafts`. Пометки `[[дописать]]` в черновике подсвечиваются.
4. Чтобы опубликовать, уберите `draft: true` и поставьте `date: 'ГГГГ-ММ-ДД'`.

## Треки

Главная страница показывает основной трек. Лаборатория живёт на отдельной
странице `#/lab` со своим оформлением (бумага в клетку, зелёный акцент).
Узел с `ref: true` в `data/map.js` — это ссылка на узел основного трека.
